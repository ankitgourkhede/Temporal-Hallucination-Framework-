## 3. Fixed: safety of the Google fallback (not in the specs)

- Google search **snippets** were treated as *primary* when the domain looked official, so a truncated, undated snippet got F ≈ 1 and full primary status. Snippets now keep their domain's Authority tier but are **never primary**: freshness uses the capped no-date rule, and severity treats them as secondary.
- Any domain *containing* "embassy"/"consulate" (e.g. a commercial visa agency) got embassy authority (0.95). That now applies only on official suffixes; everything else is `unknown`.

## 4. OPEN: design decision needed (formula flaw in the spec, not a code bug)

**CP double-penalises the correct side in a two-source conflict.** G excludes the source itself, so with exactly one government page (30 days) and one blog (45 days), *both* get G = 0, so both get CP = Severity × 1 = 0.5. The government page's trust falls from 0.81 to **0.27**, and the correct answer gets a confidence of **0.044**. The golden example never showed this because three sources agreed there. Two-source conflicts are common in your benchmark (one official page + one stale blog), so this will depress S1–S3 confidence and ECE.

Recommended fix (needs your sign-off, because it changes the golden numbers in the Phase 3 spec): compute CP from the authority-weighted **share of e's own side, including e**:
```
W(e) = Σ_{e' ∈ S ∪ {e}, value ≡ e.value} A(e') / Σ_{e' ∈ S ∪ {e}} A(e')
CP(e) = Severity × (1 − W(e))          # G itself stays as specified
```
Two-source case: government W = 1/1.35 = 0.74 → CP = 0.13; blog W = 0.26 → CP = 0.37. The minority side is penalised more, as intended.

## 6. OPEN: smaller deviations

- **Live API is a fallback, not parallel:** live fetch only runs when the index lacks the requested slot (spec: in parallel, live wins). It's reasonable for a demo, but either change the code or update `LiveAPI_Extension_Spec.md` §4 so the thesis describes what was built.
- Remaining ablations A2–A5 and A7 (no freshness / no severity / conflict modes / no primary-first / no nationality filter) are not implemented yet; A1 is.
- `diff_threshold` 0.02 is hardcoded in `offline/metadata.py` instead of read from config.
- The hedging rule penalises "may" even when it means permission ("Indians *may* enter…"), so `q_spec` = 0.5 for the official page.
- The hallucination rate measures faithfulness **to the retrieved context**, not correctness: S0 faithfully repeating the stale blog counts as *not* hallucinated, and that error shows up in **accuracy** instead. Say this explicitly in the thesis.
